# 16 — 2026 New-Age Paradigms: Agentic, Spatial, Narrative — Whole Digest

## 1. Intent-Driven & Agentic UX — First Paradigm Shift in 60 Years (Jakob Nielsen 2026)

**Shift:** From operator navigating menus → supervisor stating outcome. System plans, acts, reports. History command line→GUI → now Agent.

**Triple-Layer Model:**
1. **Intent Surface:** Where user states goal. Context-aware: voice, text, screen context, camera, calendar, hesitations. Mature = implicit intent inference system drafts prompt ambient e.g., "Summarize this repo for recruiter?" when portfolio open.
2. **Orchestration Surface (Critical Missing):** Negotiation/audit layer BEFORE execution. Shows plan, steps, tool calls, provenance, permissions. Not spinner. Planning visibility = "I will do X,Y,Z with these APIs". Tool-use disclosure = which tools why. Memory surfacing = preference active + editable.
3. **Execution/Receipt Surface:** Post-action receipt — what changed, which systems touched, assumptions used, what can be undone. Cannot rely on memory steps.

**Patterns:**
- Autonomy Slider primary UI not settings: Manual propose+confirm each ↔ Semi auto low-risk ↔ Full execute within bounds. Progressive delegation earn autonomy.
- Plan-and-Execute Preview 7-step plan allow skip/modify without restart.
- Activity Panel separate from Chat: Chat = clarification, Panel = auditable workflow log with tool I/O + time.
- Explainability on Demand + Epistemic UI: default brief status drill to reasoning/confidence map color-coded doubt weak provenance flagged not raw chain-of-thought dump.
- Recovery Routing What happened/Why/What next not "Something went wrong".

**Protocols rising:** MCP (Anthropic Model Context Protocol tool description = design artifact), AG-UI (Agent-User Interaction event stream SSE), A2UI (Google JSON UI declarations curated component catalog agent picks).

**NEX Application:** Command Palette-as-Intent Surface ⌘K → "Deploy to Vercel", "Rewrite About as timeline", "Find best React project": show plan 1.Scan /projects 2.Score stars 3.Generate summary — Approve? Assistant memory: "Using prefers remote roles (set 3w ago) [edit]" Never chat-only pair with Orchestration Sidebar Glass pane tracking steps pause/modify.

## 2. Spatial & Multimodal Interaction

**State:** Vision Pro Gen2 + visionOS3/27 2026 bleeds into 2D web.

**Primitives:**
- Input: Gaze invisible + Pinch + Voice + Hand tracking 90Hz + Spatial accessories LED+IMU. No hover cursor. Affordance via gaze-focus subtle scale/brighten + spatial audio tone + highlight. Web emulate: hover gaze, click pinch, voice fallback.
- Structure: Window (2D plane), Volume (bounded 3D), ImmersiveSpace (surrounds). Ornaments = toolbars floating slightly ahead on Z peripheral glanceable. Attachments = SwiftUI views inside 3D via RealityView. Ergonomics Seven-Zone architecture Proxemic Scaling — don't place interactives beyond 60° or 2.8m.
- Persistence: Spatial widgets remain anchored across sessions WPDC25 unlike ephemeral windows.
- Motion physical: weight, material, gradual acceleration + air resistance simulation for Z-motion.

**NEX Application:**
- Desktop as Shared Space: Windows as Volumes? About/Work in Windows, Project detail Volume with 3D hover rotate. Ornament floating Liquid Glass toolbar above each window not inside.
- Multimodal 2D: voice "Show Rust work" + gaze-like intent where mouse dwells >400ms show hint + keyboard reduce chrome context over chrome.
- Onboarding shows pinch affordance not just click.

## 3. Narrative Interfaces (Post-Dashboard Era)

**Trend Label Post-Dashboard Era:** Users want synthesis not widgets. Dashboards → Stories. Smart Timelines > grids. Generative timelines KnowledgeTrail expand/contract on question: "Show career 2021→2026 focus AI" adaptive.

**Patterns:**
- Smart Timelines generative adaptive scale.
- Narrative Scaffolding Three canvases — Narrative Panel (claims/branches), Visualization Canvas (evidence linked sentence), Timeline Canvas (provenance tree). Lets branch reasoning without overwriting.
- AdaLens Storyline: long-running agent analysis visualized as storyline where data columns = persistent characters weaving through summaries. For portfolio: commits as characters timeline.
- Single home: "Here's what changed today" + adaptive insights + semantic storyline not 12 charts.

**NEX Application:**
- Replace /dashboard with Narrative Timeline vertical: 2024 Built X evidence GitHub graph linked → Insight shift to spatial → branching Why? Inquiry board.
- Project page Story Mode compiles claims + evidence shareable narrative for recruiter.
- Don't show raw tech stack matrix; show Journey Designer→Spatial Developer with evidence chips.
